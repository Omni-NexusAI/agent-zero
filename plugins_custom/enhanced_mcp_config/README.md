# Enhanced MCP Configurator (Custom Package)

Custom/plugin-marketplace package for Agentspine MCP configuration enhancements.

## Features
- Stable server toggle behavior with `disabled` JSON flags
- Normalization for newly-added MCP server entries
- Compatible with Agentspine MCP settings flow

## Compatibility
- Agent Zero v1.7+
- Agentspine v0.9.9-pre migration track
